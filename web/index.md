## Key Discovery

Episode 8 terminal reveals [`wacky-watch.c`](/research/terminal) exists in Caine's file system.

```
/secured/
├── caine-core.lisp         [Oct 15, 1996]
├── paraphernalia-engine.dat [Oct 15, 1996]
├── [Scratch].dat           [Oct 15, 1999]
├── [Ragatha].dat           [Oct 15, 2008]
├── wacky-watch.c           [Oct 15, 1996]
└── bubble-chef.lisp        [Oct 15, 1996]
```

The website is canon. See [Terminal Analysis](/research/terminal) for full breakdown.
